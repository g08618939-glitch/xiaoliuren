# 九神小六壬九宫预测软件 MVP

## 已实现

- 农历时间起课、三数起课两种模式。
- 九神循环：大安、留连、速喜、赤口、小吉、空亡、病符、桃花、天德。
- 三行三列九宫排盘，显示初传、中传、末传。
- 三传象意、事项类型分析、五行关系接口、风险提示。
- 本地历史记录：保存、查看、删除；结果复制。
- 手机/桌面响应式界面；无后端、无账号、默认不上传数据。
- `tests.html`：程序逻辑单元测试页面。

## 运行

直接用静态 HTTPS 托管本目录，或在本目录运行任意静态服务器，例如 `python -m http.server 8080`，然后访问 `/index.html`。GitHub Pages 可直接部署 `main` 根目录。测试：打开 `/tests.html`，预期全部显示 `PASS`。

## 算法边界

九神顺序、示意九宫、三传推移和九神五行属性均集中在 `engine.js`，并带有来源/验证状态字段。当前三传和九宫是“项目自定义/待验证”规则，不宣称为统一传统标准。农历时间输入只负责接收已确定的农历月日时辰；公历到农历的闰月、子时边界仍需接入经过许可且可靠的历法库并补充对照案例。

健康事项仅提供传统文化象意说明，不作疾病诊断或治疗建议。

## 文件

- `index.html`：界面和交互
- `engine.js`：九神、三传、九宫、五行和事项分析引擎
- `tests.html`：可重复运行的逻辑测试
- `manifest.webmanifest`、`sw.js`：PWA 离线配置
